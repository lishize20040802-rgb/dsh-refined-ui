# dsh-refined-ui 0.3.3

纯 CSS 的界面精修插件：更克制的中性色（明/暗两套）、更利落的文字渲染、更安静的交互动效。不改 DSH 原有的主蓝色，不改布局和组件结构，不接管任何输入或消息。

## 它改什么

- 中性色：背景、表面、文字三级、边框、悬停底色、状态色（成功/警告/错误）、用户消息气泡底色、阴影。全部通过 `--dsw-alias-*` / `--dsw-specific-*` 官方变量实现，跟随明/暗主题。
- 文字：中文优先的系统字体栈，更清晰的抗锯齿。
- 动效：按钮、链接、输入框的悬停/按下反馈（120–200ms，减速曲线）。这些规则特异性为 0，组件自己已有的过渡不会被覆盖。
- 输入框：悬浮的大圆角卡片，带柔和阴影；点进去时边框出现一圈缓慢流动的蓝色渐变细线和外发光。
- 发送按钮：可发送时是明亮的蓝色渐变，悬停上浮，按下回弹。
- 你的消息：和侧栏选中行同款的淡蓝渐变气泡，深色文字，右下角小圆角，出现时轻微上浮。
- 助手回复：字号 15px、行高 1.82、段间距更松，代码块更圆并带细边框。
- 侧栏：悬停有平滑的淡蓝底，选中项带一层向右渐隐的蓝色底。
- 滚动条：通过 DSH 自己的滚动条变量换成更细、更淡的颜色，明暗主题各一套。
- 无障碍：系统开启"减少动态效果"时关闭所有过渡和动画。

## 与其它插件共存

- 与 dsh-lingdong：灵动自带的面板读取宿主变量，所以会自然跟随这里的配色；这里不碰它的 `.ld-*` 样式、伪元素和动画，也不改会话光晕和发送动效。
- 与桌宠等其它插件：只注入一个带 `data-plugin="dsh-refined-ui"` 的 `<style>`，不改 DOM、不监听事件。

## 新奇的交互（v0.4.0）

- **Ctrl/⌘+K 命令面板**：模糊搜索并跳转会话，或执行「新会话 / 插件 / 自动化任务」，↑↓ 选择、回车执行、Esc 关闭（输入法组词时回车不会误触发）。
- **追光**：鼠标滑过侧栏会话和输入框时，卡片里跟着指针亮起一团柔和的蓝色光。
- **呼吸光**：Agent 工作中输入框边缘流光并呼吸；完成时闪一圈完成光环。
- **点击涟漪**：点击按钮和会话时，从指针处荡开一圈淡蓝涟漪。
- **磁吸发送键**：指针靠近发送按钮时它会轻轻向指针偏移。
- **键盘**：按 `/` 直接聚焦输入框；Alt+↑/↓ 切换上/下一个会话。

以上全部遵循「减少动态效果」系统设置，停用插件后全部还原。

## 大胆一点（v0.6.0）

- **边缘极光**：Agent 运行时（思考、跑命令、开子代理都算，读取 DSH 官方的运行状态），对话区域的上、左、右三边像 computer use 那样发出蓝色流光；空闲时消失。
- **工作中的光环与萤火**：发送键外圈旋转光环，输入框边缘飘起光点；发送时迸出光点，回答完成时闪一小簇。
- **任务星图（小窗）**：有子代理在运行时，自动浮出可拖动的玻璃小窗口，窗口之间用流动的线连接表示父子关系；Alt+G 手动开关。
- **全息模式**：对话标题栏里的「全息模式」按钮（或 Alt+H）进入三维"宇宙"。中心球 DeepSeek Harness 连着所有工作区，以及插件、设置、自动化任务、新会话、新建工作区等分支；每个工作区连着自己的对话（没展开的是小卫星，点一下以卡片打开）；展开的对话是真实的对话界面，小卡片保持原样式，点击居中放大后可以直接对话（约占 1/3 屏，给周边分支留空间）。每个对话分出「命令 / 子代理 / 文件改动」三支，各自展开成具体条目，子代理自己也有同样三支。整体缓慢旋转，可拖动旋转、Shift/右键平移、滚轮缩放、搜索；工作中的卡片边缘有彩色流光。命令和文件读取自 DSH 已渲染的工具调用，其它会话的内容要打开过一次才会被记录。
- **Ctrl+K 命令面板**、**追光**、**点击涟漪**、**磁吸发送键**、`/` 聚焦输入框、Alt+↑/↓ 切换会话。

全部遵循「减少动态效果」设置（全息旋转除外，仅在进入全息模式后出现），停用插件后全部移除。

## 诊断

按 Ctrl+Alt+D 会在右下角显示并复制一份只读的界面结构摘要（标签、类名、data 属性、背景色、圆角），用来核对选择器是否对上了 dsh 当前版本，再按一次关闭。不读取任何聊天内容。

## 安装与卸载

在官方桌面应用「插件 → 安装插件 → 本地目录」中选择完整的 dsh-refined-ui 文件夹，按提示重启。包含预构建 lib，无需构建。停用或卸载后样式标签会立即移除，界面恢复原样。

## 已知限制

颜色变量的取值依据官方前端已使用的变量名和其它插件的引用推断，尚未在实机上逐项对照；首次启用后请看一眼明/暗两套主题，有不顺眼的地方告诉我，我按变量逐项微调。组件定位使用官方数据标记（`data-composer-input`、`data-chat-flow-kind`、`data-row-key`），再由脚本给输入框、发送按钮和用户气泡加上 `data-dsr-*` 属性；停用时全部移除。选择器最初由 dsh-lingdong 已在官方 0.1.7-rc.2 上核对过的稳定数据标记（`data-composer-input`、`data-chat-flow-kind`），宿主升级后请确认效果。
